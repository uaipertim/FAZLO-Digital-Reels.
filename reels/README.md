Cada Reel vive numa pasta independente (`reel-NN/`), com conceito, animação, trilha, entregas e revisão próprios. O motor, o render, a síntese de áudio e o QA são compartilhados (`core/` e `tools/`).

Novos Reels: `npm run new-reel -- 03 "Título"`.
